House rules.

01

No money ever moves.

It is a ledger and a reputation, not a wallet. Nothing in the app takes a payment, holds a balance or settles up, and that is a position rather than a missing feature — the moment real stakes change hands between friends it stops being a game and starts being regulated.

02

Colour means one thing.

A card’s fill is its status — amber awaiting, mint won, coral disputed, navy still running — so colour is never spent on decoration. Ink is then chosen by how light the fill is: an AWAITING chip was once amber-on-amber at 1.00:1, which is not low contrast, it is invisible.

03

Never invent a number.

The jar tile showed a hardcoded £23.50 to an account whose jar was empty. Every friend’s profile opened on the same 812 Form and the same 7–4 record. All of it is real data or an em-dash now: a fabricated number is the one kind of wrong that looks completely convincing.

04

Enforce it in the database.

The anon key ships inside the app bundle, so anything guarded only in JavaScript is a suggestion to anyone willing to read it. Blocking, private profiles and search visibility are enforced in row-level security and security-definer functions.

05

Reduce Motion shortens the flight. It never takes the gesture away.

The coin is thrown rather than pressed, and the first version disabled the throw entirely when Reduce Motion was on — so on any device where the animation scale is simply unset, the coin could not be flicked at all. Reducing motion should shorten the arc, not remove the interaction.

Nothing here intercepts your wheel: every act is a tall track with a position:sticky child, so the browser pins natively and scroll is only ever read — momentum, Page Down and find-in-page all behave as they would on a plain document. No GSAP, no ScrollTrigger, no Lenis, no Framer Motion — one rAF loop, one scroll read per frame. Chips, cards and reel symbols are inline SVG drawn for this page.
